# Catalogo delle Dispense

Tutte le dispense sono realizzate a supporto dell'attività didattica di laboratorio, sono sviluppate in linguaggio Markup e trasformate in presentazioni (Web + PDF) grazie all'estensione Marpit. Ogni argomento è organizzato con una specifica cartella contenente:
* Il file .md di markup.
* Eventuali immagini caricate nella dispensa.
* Export in formato PDF che può essere scaricato per sottolineature o annotazioni in locale.
