# :computer: Elenco Esercitazioni

### **File:** lib.h
:notebook: *Per Vettori*
- initVettore(int _dim, int _v[], int _value): Inizializza un vettore con un valore iniziale.
- stampaVettore(int _dim, int _v[]): Stampa i valori di un vettore su una singola riga.
- caricaVettore(int _dim, int _v[], int _min, int _max): Popola un vettore con valori casuali compresi tra min e max.
- mediaVettore(int _dim, int _v[]): Calcola e restituisce la media degli elementi del vettore.
