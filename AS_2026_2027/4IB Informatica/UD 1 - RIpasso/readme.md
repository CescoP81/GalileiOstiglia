# :computer: Elenco Esercitazioni

### **File:** lib.h
:notebook: *Per Vettori*
- initVettore(int _dim, int _v[], int _value): Inizializza un vettore con un valore iniziale.
- stampaVettore(int _dim, int _v[]): Stampa i valori di un vettore su una singola riga.
- caricaVettore(int _dim, int _v[], int _min, int _max): Popola un vettore con valori casuali compresi tra min e max.
- mediaVettore(int _dim, int _v[]): Calcola e restituisce la media degli elementi del vettore.
---
:notebook: *Per Matrici*  
- initMatrice(int _rows, int _cols, int _m[_rows][_cols], int _min, int _max): Inizializza una matrice di interi con valori random compresi tra min e max.
- stampaMatrice(int _rows, int _cols, int _m[_rows][_cols]): Stampa una matrice di interi.
- mediaMatrice(int _rows, int _cols, int _m[_rows][_cols]): Determina e restituisce il valore medio della matrice.
- matriceScacchiera(int _rows, int _cols, int _m[_rows][_cols]): Matrice scacchiera: riempie una matrice con numeri 1/0 in modo alternato simulando una scacchiera.
