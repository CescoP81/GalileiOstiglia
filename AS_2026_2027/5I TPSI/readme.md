# 5I TPSI

**Esercitazione proposta**  
Crea un file di archivio JSON per catalogare ipotetiche auto usate di un losco rivenditore. Ogni autovettura è archiviata secondo le seguenti chiavi:
- Marca
- Modello
- Anno Immatricolazione
- Provincia
- Uniproprietario
- Kilometraggio

---

Una volta creato un archivio con una decina di autovetture, con dati diversi ed inventati, procedere alla creazione di una pagina HTML che grazie a funzioni Javascript permetta le seguenti operazioni:
- Visualizzazione intero archivio.
- Visualizzazione autovetture uniproprietario.
- Ricerca e visualizzazione autovetture secondo la Provincia.
- Ricerca e visualizzazione autovetture di una determinata marca.
- Ricerca e visualizzazione di autovetture con immatricolazione compresa tra anno_x e anno_y.

---

Predisporre un'interfaccia grafica con bottoni e caselle di testo, indicando quali valori richiedono/a cosa servono.

Applicare il framework Bootstrap dall'inizio o, eventualmente, sviluppare una versione funzionante base e applicarlo in un secondo momento su una copia/duplicato della versione di base.
